# Paddy's Barbershop

## Register

**brand** (marketing landing) + **product** (booking flow). Primary public surface is the branded landing; booking is a multi-step tool that inherits the same visual system.

## Users & purpose

Customers in Balikpapan book a haircut at a multi-barber shop. They pick a barber (or no preference), a service, a date/time, and contact details. Confirmation is via WhatsApp (Fonnte); payment is at the shop.

## Brand personality

Premium, restrained, black/white. Shop-first (not individual-barber-as-hero). Calm confidence.

## Visual system (do not redesign)

- Black / white premium aesthetic
- Playfair Display headings, Inter body
- Existing spacing, layout structure, and booking UI patterns
- Rebrand + feature add only — preserve composition and motion language

## Anti-references

- Single-barber personal-brand hero as the shop identity
- Purple SaaS gradients, cream/terracotta editorial defaults, dashboard chrome on the landing page
- Payment integration or admin reporting UI (out of scope)

## Accessibility

Readable contrast on light surfaces; respect `prefers-reduced-motion`; keep keyboard-reachable booking controls.
